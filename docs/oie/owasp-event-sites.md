# OWASP-adjacent event sites (EXT-1 seed)

Curated list of event and chapter sites for the external-source registry. Compiled 2026-10-29 by fetching only each site's home page and `robots.txt` (no crawling). The machine-readable copy is `owasp-event-sites.json`; `scripts/seed_event_sources.py` turns the `suggest: true` entries into disabled **suggestions** (nothing is crawled until an admin approves them).

`Review` lists why an entry is `needs-review`. `Suggest` = created by the seed script. Robots column: crawling by generic agents (`User-agent: *`) and AI-preference lines. Where robots.txt contains only a Cloudflare content-signals preamble in comments, no `Content-Signal:` line is set, but the text is an EU Art. 4 rights reservation for any signal set to `no`; confirm before approving.

## Notes

- Not seeded (suggest: no): ticketing (Glue Up), `owasp.org` pages (host already covered by the main OWASP crawl) and Meetup.
- `appsecdays.org` (the old AppSec Days site, last edition 2020) and the guessed domains that did not resolve were left out.
- YouTube: only channels/playlists linked from an event page are recorded; ids are for the YouTube track to verify.
- LASCON asks for `Crawl-delay: 10`; the seed script records it in the suggestion notes.
- Licences: none of the sites states an explicit content licence on the home page; treat content as the organisers' unless an admin finds otherwise.
